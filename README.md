# Shortener url CLI

A cli that create a smaller url masked version of the source url.
Easy to use into the terminal: 
- enter the url -> get a short masked version of it.
- enter the short masked url -> get the source url

## Onjectives

Learned the basic of Rust through a small CLI project:

- testing
- struct
- borrowing
- ownership
- Error handling
- terminal interaction

## Stack

- Rust std for the most part.
